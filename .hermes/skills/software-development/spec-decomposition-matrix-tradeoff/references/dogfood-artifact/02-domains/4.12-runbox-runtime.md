## Required output — runtime spec

Process: one foreground, non-forking Python process; serialized scheduler; no worker pool. Limits: bounded network timeout and digest body; scan/disk/memory numeric limits set after U-001 target probe, not fabricated. Restart: systemd on failure with rate limit; watchdog only after scheduler progress; permanent config/schema errors remain loud. Shutdown: SIGTERM→stop scheduling→finish/rollback transaction→skip new send→close DB→exit; forced kill is recovered by SQLite/startup reconciliation. Boot: enable unit; validate/recover before READY; run immediate reconciliation; process pending outbox; no inbound ports. Logs of last resort: journald/unit status.
